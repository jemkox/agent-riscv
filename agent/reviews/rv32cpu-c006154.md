## Findings

1. **HIGH - rtl/csrs.sv:127 and :214 (deleted carry branch)**: this commit removed the instret rollover carry from ALL builds; `st_minstret_hi` (csrs.sv:63) is now write-only and never auto-increments. The ISS still models 64-bit instret with carry (iss/iss.py, F3), so RTL and ISS diverge once instret wraps: `hdl make mi` -> `MI TEST FAILED: 1 errors` (instret_overflow; RTL reads `instret_hi`=0xFFFFFFFF where ISS reads 0x00000000). This is an ISA-semantics regression in the *simulation* CPU, not just an FPGA concession, and it was introduced by the reviewed change itself (b9139f6 with the guard intact passed this test). The PROGRESS review-round metrics row claims `ALL MI PASS` - false in this tree.
2. **MEDIUM - Makefile:39 vs Makefile:159-160 / 211-212**: this commit dropped `build/vlt/run_hex` and `build/vlt/run_mmio` from `.PHONY`, turning the copy rules into plain file targets. Once a `run_hex_latN` binary exists, `hdl make um/ui/m7 CACHE_LAT=M` for a previously-built latency silently reuses the stale binary (re-breaking the F2 "stale runner" fix this project explicitly made). Reproduced: after `hdl make test CACHE_LAT=5`, `hdl make um CACHE_LAT=1` still printed lat5 numbers (aggregate `INSN=1917 CYCLES=4456 IPC=0.430`); the claimed 1917/3079/0.623 only came out when I invoked `build/vlt/run_hex_lat1` directly. IPC/cycle claims in PROGRESS can be measured on the wrong CACHE_LAT.
3. **LOW - Makefile:14,348**: default `FPGA_FREQ` lowered 13 -> 12.5 exactly in this commit while Fmax regressed 13.67 -> 12.88; the PASS headline hides that the threshold moved too.
4. **LOW - PROGRESS.md:450**: bare `FINAL ACCEPTANCE: MET` line remains while F4 checklist items (DSP MDU 0/8, two real Fmax improvements) are incomplete. Stale done-marker.

Positives verified: the diff (b9139f6..c006154) touches only Makefile, PROGRESS.md, rtl/csrs.sv, tb/mdiu_tb.sv - no tests/ or iss/ weakening; the new OR-of-ternary CSR read selects are semantically equivalent for simulation (all CSR localparams csrs.sv:36-51 are distinct, MTVAL default-0 preserved, MTIME aliased to mcycle as before); `tb/mdiu_tb.sv` is a genuine 46-case self-check against an `expected()` function (not hard-coded results), covering INT_MIN/-1, div-by-zero, signed/unsigned high products, and it compiles standalone against `rtl/mdiu_fpga.sv`; `hdl verilator --lint-only -Wall --timing rtl/csrs.sv` exits 0.
